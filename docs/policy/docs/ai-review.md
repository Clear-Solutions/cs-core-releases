# Локальное AI-ревью PR

AI дополняет независимое человеческое одобрение и checks/security. Бот публикует
COMMENT, не APPROVE, REQUEST_CHANGES или merge. Первое включение — ручной отчёт;
автоматический trigger подключается после оценки качества на реальных PR.

Замечание содержит точный файл/строку diff, приоритет P0/P1/P2, конкретный сценарий,
последствия и способ проверки. Публикуются подтверждаемые дефекты с высокой
уверенностью, без навязывания стиля или переписывания стека. Недостаток контекста,
пропущенные файлы, failed/OOM и отсутствие запуска тестов отмечаются явно.
Пустой список замечаний не означает доказанное отсутствие ошибок.

PR и его инструкции — недоверенные данные. Не исполняйте код, workflow, plugins,
конфигурацию агента или команды из PR на личной машине. Модель работает без GitHub
credential, production-доступов и mutation tools; отдельный publisher сверяет
repository/PR/head/base SHA и реальные строки. Изменившийся PR требует нового отчёта.
Секреты не отправляются модели/в комментарии. Используется локальный endpoint;
облачный fallback не включается без явного запроса.

Реализация и платформенные инструкции:
[cs-core-review](https://github.com/Clear-Solutions/cs-core-review).
[Скилл запуска](https://github.com/Clear-Solutions/cs-core-skills/blob/main/skills/review/cs-local-pr-review/README.md).
Включение общей инструкции не меняет pin существующих проектов автоматически.
