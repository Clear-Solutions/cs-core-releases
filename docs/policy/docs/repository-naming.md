# Типы и имена репозиториев

| Тип | Имя | Что хранит |
| --- | --- | --- |
| core | cs-core-standards | Общие правила и конфигурацию защиты |
| core | cs-core-hub | Каталог, архитектуру и планирование |
| core | cs-core-skills | Категоризированные сценарии агентов |
| core | cs-core-service-template | Повторно используемый старт Python API |
| core | .github-private | Внутреннюю страницу организации; специальное имя GitHub |
| project | cs-project-showcase | Работающий продукт: витрину команды |
| project | cs-project-sprout-hop | Самостоятельную браузерную игру |

Новый служебный репозиторий: `cs-core-<purpose>`, самостоятельный проект:
`cs-project-<purpose>`. Допустимы строчные буквы, цифры и одиночные дефисы.
`project` подходит всем платформам, а не только приложениям. Принадлежность организации
не разрешает переносить её брендинг в продукт автоматически.

Hub хранит поле `kind`: `core` или `project`, согласованное с именем.
GitHub topics `cs-core`/`cs-project` и описания `[CORE]`/`[PROJECT]` помогают фильтровать список.
Приватность, участники и PR-процесс одинаково обязательны для обоих типов.

Переименование сопровождается обновлением origin, текущих ссылок, каталога,
bootstrap, CI/CD и эксплуатационных обращений к GitHub. Исторические pinned snapshots
не переписываются: старые ссылки сохраняются как источник конкретного commit.
Не создавайте репозиторий заново под прежним именем, пока используются перенаправления.

Библиотека скиллов: [cs-core-skills](https://github.com/Clear-Solutions/cs-core-skills).
Правила подключения агентов: [agents.md](agents.md).
