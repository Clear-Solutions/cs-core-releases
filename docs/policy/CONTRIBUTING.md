# Участие в разработке

Создайте ветку от актуального main, измените правила и добавьте meaningful tests. Выполните `make check` и `make security`. Откройте PR с проблемой, результатом, проверкой и рисками. Одно независимое одобрение и успешный CI обязательны; автор не одобряет свой PR. Прямой push в main и изменение защиты для обхода PR запрещены. См. docs/git-policy.md.
