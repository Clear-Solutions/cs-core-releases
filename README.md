# easySTT · Releases

Публичные установщики easySTT — голосового ввода для Windows и Linux.
Код приложения хранится отдельно в приватном репозитории команды.

**[Скачать последнюю версию](https://github.com/Clear-Solutions/cs-project-easystt-releases/releases/latest)** ·
[Попробовать демо](https://showcase.devmops.ru/demo/easystt) ·
[Карточка проекта](https://showcase.devmops.ru/projects/b1f587a907b5c525)

| Файл | Система |
| --- | --- |
| `*_x64-setup.exe` / `*_x64_en-US.msi` | Windows x64 |
| `*_amd64.deb` | Debian/Ubuntu x64 |
| `*.AppImage` | Linux x64 |
| `*.rpm` | Linux x64 с пакетным менеджером RPM |

Релиз v0.1.3 перенесён из исходного проекта без изменения бинарных файлов.
SHA-256 каждого файла проверен по метаданным GitHub до публикации.
[Происхождение и контрольные суммы](releases/v0.1.3/manifest.json).
Это не новая сборка обновлённого main и не подтверждение запуска на всех системах.
Для локального распознавания этой версии нужен Vulkan-драйвер; диктовка Linux требует X11.
macOS и нативный Wayland пока не заявлены как поддерживаемые платформы.
Модели скачиваются в настройках приложения. Облачные провайдеры требуют личный API-ключ.

## Участие и поставка

`make setup`, `make check`, `make security`. Python 3.12+, Git, Linux x64
для закреплённых инструментов проверки безопасности; локальные проверки манифеста
работают на macOS/Windows/Linux. GitHub CI проверяет политики, manifest и workflow,
CD сохраняет каталог проверенного main с его SHA. Установщики не включены в этот архив.
[Поставка и откат](docs/deployment.md) · [Инструкции агентов](AGENTS.md).
Изменения: ветка → PR → один независимый ревьюер → зелёные checks/security.
